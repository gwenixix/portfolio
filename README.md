# Black Ink by Z. portfolio

A static site for GitHub Pages. No build step.

## Edit it
- All text, brands, and photo paths live in `content.js`.
- Put photos in `images/` and reference them, e.g. `image: "images/acme.jpg"`.
- Add a brand by copying a block inside `brands` in `content.js`.
- Look and layout: `style.css`. Page structure: `index.html`.

## Publish
Push to GitHub, then Settings > Pages > Deploy from branch `main` / root.
